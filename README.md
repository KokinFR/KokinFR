### 🌱 AgroIrriga — Agricultural automation

**Simulation prototype in development**

An irrigation automation prototype for small gardens, combining a control core, a local API, and a web dashboard.

- C++17 irrigation controller with automated tests.
- ESP32 simulation in Wokwi.
- React dashboard with moisture readings, history, and simulation controls.
- Local FastAPI backend with SQLite, JWT authentication, and user roles.
- Safety behavior for emergency stops, sensor faults, and maximum pump runtime.

**Stack:** C++17 · Python · FastAPI · React · TypeScript · SQLite · Wokwi

### 📊 B3 Financial Analysis — Free Cash Flow Yield

**Undergraduate thesis / research in development**

Building a tool to support the analysis of B3-listed companies using financial statements and market data, with **Free Cash Flow Yield** as the central metric.

- Processing annual financial statements from the Brazilian Securities Commission (**CVM**).
- Structuring financial data for company analysis and comparison.
- Defining a methodology that considers the latest annual DFP available at the time of each analysis, including restatements.
- Exploring data analysis and visualization with Python.

**Focus:** Python · Pandas · Financial data · CVM · Free Cash Flow Yield
